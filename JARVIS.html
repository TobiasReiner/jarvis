    Schlüssel auf diesem Gerät merken
    Für Wetter, News, Quiz und Plaudern reicht der Sparmodus völlig – damit kostet dich eine Frage rund einen halben Cent. Für Unterrichtsplanung oder komplizierte Fragen lohnt sich Standard. Ohne eigenen API-Key (also innerhalb von claude.ai) wird diese Einstellung ignoriert.
    In der selbst gehosteten App-Version ist ein eigener Claude API-Key nötig (console.anthropic.com → API Keys). Läuft die Seite innerhalb von claude.ai, Feld einfach leer lassen. „Merken" funktioniert nur in der gehosteten Version und speichert nur lokal auf deinem Gerät.
    Diagnose läuft …
    Bleibt die Stimme stumm? Häufigste Ursache am iPhone: der Stummschalter – die Sprachausgabe respektiert ihn. Schalter auf laut + Lautstärke hoch. Danach: Siri-Stimmen laden unter Einstellungen → Bedienungshilfen → Gesprochene Inhalte → Stimmen → Deutsch – die erscheinen dann hier in der Liste und klingen erstklassig.
    Wichtig: Innerhalb von claude.ai blockiert die Sicherheitsrichtlinie externe Dienste – der ElevenLabs-Modus funktioniert nur in dieser gehosteten App-Version. Voice-ID findest du bei ElevenLabs unter „Voices" (deutsche Multilingual-Stimme wählen).
